# SpaceX Event Gateway (NestJS)

This repository contains the NestJS migration of the original SpaceX Event Gateway.

## Legacy implementation

The original Node.js/Express implementation has been preserved in the `legacy` branch for historical reference.

## What's new

- NestJS architecture
- Domain-driven modules
- Strong TypeScript contracts
- OpenTelemetry tracing
- Prometheus metrics
- Redis
- RabbitMQ
- MongoDB
- SSE event streaming
- React + Vue + Angular frontends
- Nx monorepo
